## 1. 背景(用户提供)

1. 早期代码本地开发 → 因 mini 承载力不足+项目扩大,迁移至服务器 `8.138.181.177`。
2. 服务器开发中发现旧架构不理想 → 决定**重新设计架构**,分流到三仓库:**TradingAgent(交易全闭环)/ MarketGraph(宏观研究)/ SharedSignals(数据采集)**。
3. **本地 mini 只保留交易执行层**:同花顺只能通过 mini 上的 Hermes 执行模拟盘 + 未来实盘的账户同步与交易执行。需验证原实现路径是否迁移、能否正常使用。
4. MarketGraph 也在架构重构中,cron 要特别注意迁移/整合/停止/删除。
5. A股/加密/美股/预测市场及未来横向市场,都是 TradingAgent 下的子市场。
6. **推进优先级**(item 11):
   - P1:先保障 A股/加密/美股/预测市场 **影子盘闭环 + 可迭代复盘**
   - P2:再保障 加密/美股/预测市场 **模拟盘闭环 + 可迭代复盘**
   - P3:然后 A股模拟盘 + 实盘(模拟盘经 mini Hermes 执行、不碰账户信息;实盘经邮件发用户执行,mini Hermes 同步账户信息)
7. 原系统代码:符合新架构的迁移,可利用的优化后迁移,无效的验证后删除,缺的重写。原系统应归至 Archive 避免混淆。

## 3. 审查发现的缺陷(7 路委派 + 我亲自验证)

> 来源标注:[K-A]=kimi-A, [K-B/C/D/E], [C1]=codex-1, [C2]=codex-2, [自验]=我亲自验证

### P0 严重(阻断实盘)

1. **资金层未隔离**:`capital_ledger`/`position_ledger` 无 `capital_layer` 字段,三层资金写同一 CSV;shadow 路由返回 `executed=True`。[K-C + C1 + C2 三方共识]
2. **实盘硬边界是默认 flag 非硬门禁**:`requires_manual_confirm=False` 或 `strategy_stage` 伪装 → 直接 SSH 发真实买卖;`cancel_order()` 无确认;`route()` 不强制 `check_graduation`。[K-C + C1 + C2 + 自验 四方]
3. **condition_generator `datetime.timedelta` bug**:`from datetime import datetime`(类非模块)却调 `datetime.timedelta` → AttributeError,带过期日条件静默丢失,打断核心漏斗。[C2 发现,自验 ✅]
4. **position schema 不匹配**:台账输出 `avg_price/cost_basis`,风控/退出读 `cost/entry_date/high_price/thesis` → 止损/时间退出/逻辑证伪静默失效,状态机卡"持有"。[C1 monkeypatch 验证]
5. **T+1 未强制 + 自然日 bug**:`can_sell("2026-06-27","2026-06-28")==True` 用自然日非交易日;helper 孤立,卖出路径未调用,台账不存 open_date。[C1 验证 + K-D]
6. **信念分与风控脱节**:LLM 单轮对辩给高 belief_score→高权重,pre_trade_check 不感知 belief;软限叠加后权重 0.000001 仍可通过;无最低权重门槛。[K-B]
7. **hermes_bridge 命令注入**:SSH cmd f-string 拼 ts_code/limit_price 无白名单。[C1 + C2 + 自验]
8. **hermes_bridge `result[stderr]` KeyError**:line 155/179 未定义变量,SSH 失败路径 NameError。[C1 + C2,自验 ✅]

### P1 高

9. 无调度层:所有模块纯函数库,无 cron/主循环(README 称 5min/10min 闭环但代码无)。[K-A/B/D + C2]
10. 复盘→调权闭环断:复盘只输出建议文本,不写回 weights.yaml,无 OOS/冻结期/防过拟合。[K-D + C2]
11. 自愈空壳:heal handler 返回"已平仓"字符串就记 healed=True,未接真实动作 → 虚报修复。[K-D + C1 + C2]
12. benchmark 断连:benchmark.py 用 placeholder 0.0,不调 benchmark_tracker,"vs 基准"塌陷。[K-D]
13. CSV 无并发锁:read-modify-write 无锁 → 多策略并行写台账覆盖/双减仓。[K-C + C1]
14. shadow_broker P&L bug:卖出不查持仓(可负仓)、净回款直接减 cost_basis、只看单日忽略前日库存 → 污染 shadow→real 升级判断。[C1]
15. 相关性降权覆盖 bug:多次降权只生效最后一次(赋值非累积)。[K-B]
16. black_swan 依赖外部 bool 标志(policy_shock/vix_spike)无自动生成 → 永不自动触发。[K-B]
17. 裸 import 错误:heal.py/patrol.py/constructor.py 裸相对名导入 → 作为包导入 ModuleNotFoundError,**风控/自愈/组合模块跑不起来**。[C1 验证]

### P2 中

数据缺失静默中性化(0.5);集合竞价 STUB;告警无去重/限流;101 cron 未拆分(全在 MarketGraph deploy);硬编码 /opt/investment 路径;weekly_state 互斥 bug(正收益豁免淘汰);trade_audit_trail 非完整 DAG;daily_reconcile 只对数量;min_float_mktcap_yi 未实现;strategies/ 全空。
