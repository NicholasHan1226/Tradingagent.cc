# 解禁事前股东户数变化条件层预注册（research_only）

- 制定日期：2026-08-24。性质：冻结预注册，先于任何分桶收益读数合入主线。
- 绑定：holdernumber 管道假设（#468 抓取器模块文档）：解禁事前户数收缩=
  强手集中的筹码结构，扩张=散户接盘薄——cyq_perf 价格侧（78% 解禁发生在
  浮筹被套、winner-rate 单调梯度）的行为侧对应物；flow 侧面板
  （holdertrade/repurchase）与质押股数面板都看不到「现在谁持有流通盘」。
- 数据面：`holdernum_*.csv` 按股文件 975 只（宇宙 1000 只中 25 只全史无披露，
  无文件属标签事实非错误），字段 [ts_code, ann_date, end_date, holder_num]，
  覆盖公告流回溯至 1990 年代、最新至 2026-08-24 当日。

## 冻结定义 D1–D4

**D1 锚窗**：候选行=holder_num 非空的披露行，ann_date ∈ [entry−365 自然日,
entry)，严格不含入场日。**快照单位=公告日**：同日多期披露（合法组合，实测
14,410 组、同键冲突为 0）先按公告日去重，每组保留 end_date 最新、再并列时
holder_num 较大的一行——与 pledge 面板「最新快照一张」的公告即观察单位逻辑
同构。锚行=去重后窗口内 ann_date 最大的一条；**对比行=紧邻锚行的前一条公告
快照**（跨公告比较，其 ann_date 也须落在窗口内）。变化率因此度量「相邻两次
披露之间的户数演变」，不把同一份公告内的两个期间互为趋势。

**D2 分桶**：变化率 = 100 × (锚行户数 − 对比行户数) / 对比行户数，固定边界
±5.0（先验注意力线，非数据挖掘分位）：
- `contract`：变化率 ≤ −5.0（事前筹码收缩）；
- `stable`：−5.0 < 变化率 < +5.0；
- `expand`：变化率 ≥ +5.0（事前散户化扩张）；
- `no_snapshot`：合格非空快照不足两张，或对比行户数 ≤ 0 的退化情形。

**H1（冻结）**：信号层主对比 = `contract` 对 `expand` 均值与胜率双高。
机制绑定：解禁供给落地前户数收缩=强手已集中（抛压承接结构），扩张=浮筹
散户化（接盘薄）。`no_snapshot` 与 `stable` 仅作参照/描述。

**判定冻结**：家族标准——rule 臂某桶相对未滤 rule 臂均值+胜率双高且 n≥30
才进观察名单。覆盖率事实预先声明（下表）：两臂双快照可得性 100%，rule 臂
按全臂分布外推预期 contract/stable/expand ≈ 89/179/89 ⇒ **规则层各桶有望
真实达到 n≥30**——这是继 pledge（72%）之后第二个高覆盖方向性面板，与前两个
龙虎榜低覆盖面板（预告基准情形）性质不同。若 rule 层出现达标桶，按冻结标准
进观察名单；多重比较纪律（第 12 面板）下仍不作部署候选。

**D3 插补与容错**：零插补；holder_num 为空的披露行不是快照（整行跳过，
QA 计数）；缓存无任何 holdernum 文件 fail-closed
`HolderNumStudyError("holdernum_cache_missing")`；时间轴一律用 ann_date
（披露日=信息可见日，杜绝 look-ahead；holdertrade 家族「只有 ann_date 干净」
教训的同款预防）。文件名权威映射 ts_code。

**D4 引擎口径**：锁定基线 after 口径（涨停真实性修正后）、成本 15bps 往返、
loaders 与家族完全一致；一次性读数，读前不跑任何分桶收益。

## 覆盖率事实表（读数前测定，纯标签计数，未碰任何收益数据）

|---|---|---|---|
| all | 1035 | 408 (39.4%) | **1035 (100%)** |
| rule | 357 | 147 (41.2%) | **357 (100%)** |

- 变化率分布（all 臂）：p10 −13.1 / p25 −5.9 / 中位 −0.4 / p75 +7.8 /
  p90 +25.9 ⇒ ±5 边界切出约 25% / 50% / 25% 的对称三桶。
- 锚行陈旧度：均值 51 自然日 / 最大 178（365 上限极少约束）。
- 空 holder_num 行按时代分布（空值率近年上升，佐证「公告存在但户数未填」
  已知坑必须显式处理）：2018–2020 501/21,056 (2.3%)；2021–2023
  3,542/14,561 (24.3%)；2024– 13,419/85,916 (15.6%)。
- 同 ann_date 多期披露组 14,410 个全部为不同 end_date 的合法组合，
  同键冲突 0 ⇒ 快照单位=单行、tie-break 按 end_date 是数据结构的忠实
  描述而非修补。
