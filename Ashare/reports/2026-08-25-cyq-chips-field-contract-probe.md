# cyq_chips 成本分布面·字段契约与数据路径探针（research_only）

- 制定日期：2026-08-25。性质：候选台账 C25 的可行性证据文件；只测契约与
  覆盖事实，未计算任何收益、未冻结分桶。
- 背景：#25 筹码研究只用了 cyq_perf 的标量 `winner_rate`（underwater/mid/
  profit 三桶已读数并接线滚动面）；C25 指向同一数据族的**分布深度轴**
  （Tushare `cyq_chips` 独立接口）。

## 字段契约（API 探针实测）

单票限窗调用返回列：`ts_code, trade_date, price, percent`。
样本：000001.SZ，20260801–20260815，1040 行 ≈ 11 个交易日 × 约 94 个价
位档/日。语义：每个交易日把全部流通筹码按成本价分档，`percent` 为该价位
档筹码占比。这是 cyq_perf 标量之外的完整成本分布形状信息。

## 数据路径判定（关键结论）

**本地全量回填被量级否决**：按约 94 档/日、2018 起 2100 会话估算，单票
全史 ≈ 180 万行 ≈ 600 个分页调用，973 只 ≈ 58 万次调用——不可行，且与
生产采集共用配额时有加剧采集服务失败的风险（该服务当前已有慢性失败，
另案交接）。

**正确路径 = 生产库滚动窗**：root 通道只读实测
`provider_dataset_rows WHERE dataset_id='cn.dataset.cyq_chips'`：

| 事实 | 值 |
|---|---|
| 总行数 | 2,429,510 |
| 采集时间跨度 | 2026-08-12 → 2026-08-25（在产约 13 日滚动窗） |
| payload 结构 | `{"ts_code","trade_date","price","percent"}` 与 API 一致，quality_state 全 valid |
| 登记怪癖 | partition_value 全部为 NULL（日期只在 payload 内），后续覆盖率 SQL 必须走 payload_json 或 receipt 关联 |

按 2.43M ÷ 13 日 ÷ ~94 档估算日覆盖约 1900–2000 只——是否全市场口径
**待证**（引擎期用多日 distinct ts_code 复核）。

## 设计方向（预注册前置声明，非冻结）

历史锚不可得 ⇒ C25 采用**前瞻门模式**（valuation[low_le25]/holdertype
[incentive] 先例）：预注册声明 entry ≥ 门开日的信号才入样，n≥30 首读为
最早合法判定点。

候选度量族（边界须待分布事实测定后冻结，本文不冻结任何数值边界）：
- **成本位置**：(成本均价 − 锚日收盘)/收盘——区分上方套牢密集（负向机
  制，同 #445 underwater 家族）与下方承接密集；
- **分布宽度**：成本分布分位间距（离散=无明确套牢/承接结构）。
两度量都需要锚日 close 做 join（本地 daily 缓存可得），边界探针在
close-join 管道就绪后执行。
