# A股事件信号预注册评估标准（research_only）

- 制定日期：2026-08-23。性质：**纯研究 / research_only / not_promotion_evidence**。
  本文件在滚动样本积累**之前**固定三信号跟踪的升降级判定规则，防止样本攒够后
  回头挑选对自己有利的标准。本文不授予任何资金权限；晋级到模拟盘另走
  `event_catalyst_promotion` 流程，与本文件无关。
- 适用对象：`event_signal_lockup_tracker.py` 跟踪的三个信号——`lockup`
  （解禁超跌修复）、`earnings_pos`（预增披露事前窗口）、`earnings_neg`
  （预减披露落地修复），均记入共享 SampleJournal 的 `shadow_research` 层。

## 口径

- 收益为绝对收益，统一扣除 **15bps 往返成本**（佣金约 2.5bps×2 + 印花税 5bps +
  过户费约 0.2bps + 滑点预留 5bps；模型依据与敏感性见研究报告中「成本后真实边际」）。
- `lockup` 只在**弱市**子集上评估（#409/#411 已确认震荡/强市扣完成本后无边际；
  市场环境标签由跟踪器自动附加）。
- `earnings_pos` 用其**事前交易窗口**（预告公告次一交易日收盘入场 → 披露日收盘
  退出，2026-08-23 起由 #413 提供）；`earnings_neg` 用已标注的事后修复窗口。
  对照组读数不参与升降级判定。

## 固定评估点（milestone）

只在样本到达下列里程碑时做判定；期间允许查看报告，但**不得据中途读数调整阈值或提前判定**：

| 信号 | 一个评估点的触发条件 |
|---|---|
| lockup | 弱市已标注样本每满 **30** 条 |
| earnings_pos | 该信号事前窗口已标注样本每满 **50** 条 |
| earnings_neg | 该信号已标注样本每满 **50** 条 |

## 判定规则（每个评估点，三选一）

设评估点上净均值 = mean_net（bps）、净胜率 = win_net：

1. **通过（keep）**：mean_net > 0 **且** win_net ≥ 52%，且把积累期按时间对半分后
   两半方向一致（两半 mean_net 同号）。通过则继续按同一标准积累下一评估点。
2. **失败（fail）**：mean_net ≤ 0 **或** win_net ≤ 45%。失败即停止积累该信号，
   报告中标注 failed-in-current-form；重启需要新的研究假设和重新注册的标准，
   不得沿用本文件。
3. **灰区（extend once）**：其余情形。样本翻倍后再判一次，**只延一次**，
   第二次仍为灰区按失败处理。

## 阈值依据（2026-08-23 固定，未使用任何滚动数据拟合）

- lockup 弱市历史分层：净均值 +91.6bps、净胜率 55.2%（top-1000，n=308）。
  通过线 52% 取历史水平减约 3 个百分点容错；失败线 45% 明确低于随机。
- earnings 两信号大样本方向成立但幅度未做过成本口径分层，取与 lockup 一致的
  对称阈值，避免逐信号调参。

## 变更纪律

修改本文件必须在研究报告记录变更日期与理由；新标准只适用于其后到达的评估点，
不得追溯改变已做出的判定。评估结果每次落盘到研究报告的跟踪器章节。

## 边界

全部内容为描述性统计与研究治理约定，不构成预测概率、投资建议或任何晋级证据。
