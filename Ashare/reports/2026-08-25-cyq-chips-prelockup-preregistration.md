# 解禁事前筹码成本位置条件层预注册（research_only）

- 制定日期：2026-08-25。性质：冻结预注册，先于任何分桶收益读数合入主线。
- 绑定：cyq_chips 生产数据面（候选台账 C25；契约与路径证据见
  `2026-08-25-cyq-chips-field-contract-probe.md`）。主度量是**成本分布的
  距离几何**：(成本均价 − 现价)/现价。
- 与 #445（cyq_perf winner_rate 三桶）的关系声明：winner_rate 是价格两侧
  **质量占比**（多少筹码获利），本层是**加权距离**（获利/套牢有多深），
  几何不同但相关。若读数梯度与 #445 完全共线，按「同信息再参数化」记为
  确认性读数而非新轴发现，不重复入计数。

## 冻结定义 D1–D4

**D1 锚窗**：入场日前最后一个可用会话的生产库 cyq_chips 快照——严格
`trade_date < entry_day` 的最大可用会话的逐价位 `{price, percent}` 分布；
close 取本地日线缓存同会话收盘。**前瞻门**：仅 entry ≥ 门开日的信号入样
（门开日=本 PR 合入后首个完整交易日，引擎 PR 中落为常量）；历史锚不可得
已由契约探针证实（生产窗 2026-08-12 起）。

**D2 主度量与分桶**（构造性互斥）：
- `pos = (成本均价 − close) / close`，成本均价 = Σ(price×percent)/Σpercent；
- `low`：pos < −3%（获利结构：成本显著低于现价）；
- `normal`：−3% ≤ pos < +5%；
- `high`：pos ≥ +5%（套牢悬顶：成本均价显著高于现价）；
- `no_data`：锚会话无快照、分布空或 close 缺失（参照行，不进主对比）。

次度量 `width = (p90价 − p10价)/close` 同面板描述性记录（narrow <15% /
normal / wide ≥30%），不设方向承诺、不作独立判定。

**边界来源声明（读数前冻结）**：全股票日边际分布实测（生产库 20260812–
0824 九个会话 × 本地日线可 join 子集，n=4588）：pos p25/p75 = −2.60% /
+6.23%，width p25/p75 = 14.58% / 29.17%；取整注意力线 pos −3%/+5%、
width 15%/30%。冻结发生在任何分桶收益计算之前。背景事实：样本期市场中
位成本位在现价上方 +1.72%（p50），39.0% 股票日成本均价低于现价——弱市
套牢结构为本层提供了真实的两态分离。

**H1（冻结，负向主对比）**：rule 臂 `high` 桶对未滤 rule 臂**均值与胜率
双低**。机制绑定：解禁供给悬顶叠加存量套牢盘解套抛压=双重供给；`low`
桶作次级描述性对照（获利承接结构，与 #445 profit 桶正向读数同向）。

**判定冻结**：家族标准——rule 臂某桶相对未滤 rule 臂均值+胜率双低（或双
高）且 n≥30 才进观察名单；**首读最早合法判定点=任一实质桶在 rule 臂内
累积 n≥30**（前瞻门模式下允许跨月等待）；第 20 个条件层面板多重比较纪律
下无论结果均不作部署候选；反向使用需独立重新预注册。

**D3 插补与容错**：零插补；生产窗覆盖爬坡期（日覆盖 1579–5543 只波动）
导致的缺快照统一落 `no_data` 参照行单独计数，不进入主对比；percent 合计
≤0 的异常分布丢弃并计数。

**D4 引擎口径**：锁定基线 after 口径（涨停真实性修正后）、成本 15bps 往
返、loaders 与家族完全一致（cross_tab 共享机器）；一次性读数，读前不跑
任何分桶收益。
