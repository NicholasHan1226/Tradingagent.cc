# lockup 样本单元口径预注册决定（research_only）

- 日期：2026-08-26。性质：#586 待决事项的口径落定，先于任何经济事件
  级判定计算合入；同款先例=反向候选队列标准冻结（读数前制定）。
- 可推翻性声明：本决定由研究管道按既有授权作出，Nicholas 可随时推翻；
  推翻成本为零（行级预设 `lockup_rule` 原样保留，两口径可并行复算）。
  任何部署判断从不依赖单一口径。

## 决定

**lockup 家族的正式判定样本单元自本决定起采用「经济事件」粒度
（symbol × 解禁日），新预设名 `lockup_rule_events`。**

### 聚合规则（冻结）

1. 先剔除跨运行重发现伪影（`dedupe_samples`，#586）。
2. 事件键 = (剥离 tracker 序号后的 symbol 段, `event_date`)；
   `event_date` 与 ID 内嵌解禁日逐位一致（彩排导出 197/197 验证）。
3. **事件级规则臂谓词 = 交集语义**：事件内每个有比例标注的披露档都须
   regime=weak，且任一有标注档落入回避带 3–5% 即整个事件出局；
   全部档无标注的事件出局；无标注档不否决但不使事件入队。
   理由：「回避带」是事件层经济判断（当日解锁画像是否落在问题区间），
   交集方向保守（缩小样本、推迟任何正向声明），与去重的安全方向一致。
4. 事件取值 = 该事件任一记录的 `post_return_bps`（组内逐位一致已验证，
   同一价格路径）；净 = 毛 − 15bps 不变。
5. 门柱数字不变（n≥30），但 n 的含义自此为**独立经济事件数**；
   「翻倍到 ~200 行」的旧表述作废。第二次（最终）判定的触发条件 =
   经济事件数 ≥30 或滚动窗再积累一个季度，以先到者为准。

### 三方案取舍记录

| 方案 | 取 | 舍的理由 |
|---|---|---|
| 一 行级原样 | 连续性 | 门柱 n 语义失真，聚类重复放大量级（+128.7 vs +36.9 vs −18.3） |
| 二 事件级（选定） | 独立性成立、与可交易机会一一对应 | 与既有入档口径断裂（已在 #586 报告明示断点） |
| 三 记录级折中 | 数字连续 | 独立性仍破，语义模糊 |

### 对既有读数的影响

- #571（GRAY）：结论在行级与记录级稳健，保留有效；其 n 与量级自本
  决定起不再作为第二次判定的比较基线，基线改用事件级重算。
- 第二次判定尚未执行，因此本决定不改变任何已入档判定结果，只约束
  尚未发生的计算——这正是口径决定必须落在计算之前的理由。
