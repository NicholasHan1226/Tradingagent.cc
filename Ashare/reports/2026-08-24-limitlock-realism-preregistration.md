# 涨停真实性修正：预注册标准（research_only）

- 制定日期：2026-08-24。性质：预注册文档——以下全部定义与阈值在本 PR 合入主线时
  冻结，后续引擎实现 PR 只实现、不改阈值；读数在引擎落地后一次性产出。
- 动机：`event_paper_baseline_sim` 现行口径假设事件日收盘与持有期第 5 会话收盘
  都能按收盘价成交。当股票当日**封死涨停**（收盘=涨停价）时买单排在巨量买一，
  收盘价成交不可达；封死跌停时卖单同理。基线读数（#423）因此含系统性不可成交腿。
- 数据源：`limitlist_daily` 名单（#442 落地，1633 交易日，自 20191128 起）。
  用名单字段 `limit` 作为封板事实源，**不用涨跌幅近似**——主板/创业板科创板/
  北交所/ST 的涨停幅度不同（10%/20%/30%/5%），名单本身无此歧义。

## 预注册定义（冻结）

1. **D1 入场锁死判定**：信号 `entry_day` 当日该股出现在 limitlist 当日文件且
   `limit == "U"`（收盘封死涨停）⇒ 该笔入场按不可成交处理，**整笔信号跳过**
   （不做顺延重入场），计数 `skipped_locked_entry`。
   - 理由：收盘封死的涨停板在收盘集合竞价无法保证按涨停价买入；即使盘中开过板
     （`open_times > 0`），收盘时点的可达性仍不成立，故不做 open_times 细分。
   - 不触发跳过的情形：`Z`（炸板，收盘未封死）、`D`（收盘封死跌停——买入反而
     可达）、当日不在名单。
2. **D2 出场锁死判定与滚动**：信号 `exit_day` 当日该股 `limit == "D"`
   （收盘封死跌停）⇒ 卖出按不可成交处理，沿该股自身交易日历向后逐会话滚动到
   **第一个不在 D 名单的会话**，以该会话收盘价退出；成本口径不变。
   - 计数 `rolled_exits` 与滚动长度分布（1/2/3+ 会话）；滚动超出数据末端时按
     最后可用会话退出并计数 `rolled_to_end`。
   - 不触发滚动的情形：`U`、`Z`、不在名单（封死涨停不影响卖出可达性）。
3. **D3 覆盖边界**：`entry_day` 或 `exit_day` 早于 20191128（无名单数据）⇒
   保持现行口径不修改，单独计数 `pre_coverage_untouched`；**禁止插补**。
4. **D4 口径不变性**：其余一切不动——成本 15bps 往返、槽位制仓位、事件后首个
   可用会话收盘入场、5 会话持有期定义、信号分类、rule 臂过滤。唯一改动是
   D1/D2/D3 三条。
5. **D5 判定性质**：这是**真实性修正，不是 alpha 声明**。诚实先验：跳过涨停
   入场可能剔除强动量延续样本，净收益可能下降——这是换取成交可达性的可接受
   代价。本修正不设 KEEP/FAIL 门柱、不构成晋级证据；产出为修改前后并列读数。

## 读数计划（引擎落地后一次性执行）

总净收益、月均净、最差月、最大回撤、笔净胜率、n、
`skipped_locked_entry`、`rolled_exits`（含长度分布）、
`rolled_to_end`、`pre_coverage_untouched`。
