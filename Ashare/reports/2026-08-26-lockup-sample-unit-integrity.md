# 规则臂样本单元完整性调查：行数≠事件数（research_only）

- 日期：2026-08-26。性质：测量完整性缺陷的发现、定位与影响评估；
  起因是彩排对账中一个自相矛盾的计数（journal 增 186 行 vs 评估器全量
  n=100）。零新桶定义、不移动门柱；先于任何第二次 lockup 判定合入。

## 发现链

1. 彩排 journal 从 577 → 763 行（+186），最初误读为「CI 取消运行造成
   的自愈回填」。
2. 逐 ID 对账推翻该读法：186 行与 run9 的 journal **和** ledger 均零交集，
   但剥离 `tracker-\d+` 段后按事件元组对比，130 个元组全部已存在于旧集——
   **同一事件每次运行被重新编号再记账**，`+186` 是重复记账不是回填。
3. 追查导出内部：单次导出的 `labeled_outcomes.lockup` 197 行也只有
   138 个唯一披露记录——重发现伪影在单次导出内就存在。
4. 再深一层：规则臂 100 行按「symbol × 解禁日」聚合只剩 **11 组**，
   且每组内 `post_return_bps` 完全一致（11/11 组零差异）——同一公司
   同一解禁日的多个持有人披露各行记一条，共用同一条价格路径。

## 根因与修复

- **根因 A（工具伪影，已修）**：lockup 的 event_id 内嵌每次运行重新生成
  的 `tracker-NNNNNN` 发现已序号，导致跨运行去重失效、导出携带重发行。
  earnings 两臂 ID 内嵌 symbol+报告期，天然唯一（165/165、206/206 零
  重复），不受影响。
- 修复：评估器所有预设读取后经 `dedupe_samples()` 按
  `stable_event_key`（剥离 tracker 序号段）折叠，CLI 打印
  「原始行 → 独立事件」留痕；无 event_id 的行永不合并（fail-safe）。
  15 条测试全绿；真实导出复算：lockup_rule 197→69 且判定仍 GRAY、
  earnings 两臂 0 剔除——冻结标准未动，纯输入卫生。
- **根因 B（方法论问题，未擅自修）**：持有人粒度多重性是跟踪器的原生
  设计（每条 share_float 披露 = 一个样本），不是 ID 伪影。样本单元应
  取哪一层（行 / 披露记录 / symbol×日）属于冻结方法论决定，必须在
  第二次 lockup 判定计算**之前**预注册式敲定，不得由本工具静默折叠。

## 对既有入档读数的影响

- **#571（GRAY 判定本身）**：行级与记录级判定一致（GRAY 稳健），但
  入档量级 +128.7bps 与 n=100 高估了信息含量；有效独立样本 ≈11，
  远低于任何门柱语义。
- **#584 衰减分解**：全部表格以行为权重，被持有人多重性放大——例如
  repurchase[active] 晚半 +621.1/n=11 恰为 002782.SZ 单一事件的 11 行；
  valuation[high_ge75] 翻转的实际事件支撑可能仅 2–3 个。方向性观察仅
  作线索，量化表不可再引用；详见该报告更正附注。
- **8·31 计划**：earnings_pos/earnings_neg 首次正式判定**完全不受影
  响**（ID 天然唯一），按 #583 解读矩阵照常执行。受影响的只有 lockup
  第二次判定的时间表与口径（见下）。

## 待决事项：lockup 第二次判定的样本单元（计算前必须敲定）

- 方案一（行级原样）：延续 #571 口径，接受聚类重复，报告中并列披露
  事件级读数作对照。优点：连续性；缺点：门柱 n 语义失真。
- 方案二（symbol×日聚合）：每经济事件一票，估值/比例等属性取当日任一
  在臂行的并集或多数。优点：独立性成立、与可交易单元一致；缺点：与
  既有入档口径断裂，需明示断点。
- 方案三（记录级 + 聚类稳健性陈述）：以 69 为判定底座，同时声明独立
  事件数。折中但语义模糊。
- 倾向：方案二，理由是判定对象本来就是可交易的承接机会而非披露条数；
  但此倾向**不是决定**，落定前 lockup 不做第二次判定，也不据此调整
  任何观察名单项。
