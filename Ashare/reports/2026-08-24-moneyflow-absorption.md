# 大单承接吸收研究（2026-08-24，#21 首读）

`Ashare/event_moneyflow_absorption_study.py` · research_only / not_promotion_evidence
数据：moneyflow_daily 全市场明细（2096 会话全量，0 空 0 失败）· 同一引擎同一槽位约定

## 假设与度量（预注册于 #431）

- H1：sell_off 事前大单净买入高的子集 post-5d 净收益更高。
- H2：该分离度独立于市场环境与两融状态层。
- 度量：事前 5 会话大单+特大单净买入额 ÷ 前 20 会话日均总成交额（无量纲）；
  窗口严格先于入场日；固定半开边界 ±0.10（校准自数据：中位 −0.078，
  |ratio|≥0.10 占 53%，非样本分位数拟合）。

## 数据质量

- 覆盖率 **98.8%**（1023/1035 信号可标注）——远高于两融层的 56%，是迄今
  最干净的一次信号层读数。
- 抓取器截断预警核验：预警日（5529–5543 行）经宇宙前缀覆盖抽查确认
  **非截断**（缺席者为当日停牌股），行数增长系市场自然扩容。

## 读数四：市场层 × 吸收联合交叉（H2 判定）

n=1023；单元格 n / 净bps / 胜率：

| market\absorb | outflow | balanced | inflow |
|---|---|---|---|
| deleverage | 98 / −3.7 / 0.53 | 161 / **+230.5** / 0.58 | 11 / +163.5 / 0.64 |
| neutral | 207 / **+80.2** / 0.53 | 284 / +51.5 / 0.51 | 14 / +80.2 / 0.50 |
| expansion | 122 / +18.0 / 0.43 | 125 / +46.2 / 0.50 | 1 / −505.1 / 0.00 |

**H2 判定为否——吸收梯度不独立于市场层**：balanced 的优势几乎全部集中在
市场去杠杆行（+230.5 vs −3.7），中性市场行内排序反转（outflow 反超），
扩张行差距缩小。rule×balanced 的边际组合增益很可能主要是去杠杆 regime
效应的再表达，而非独立的承接信息。

## 结论与判定

1. **首个通过「梯度不反转」检验的条件**，且增益方向与机制假设一致；
   但幅度仅 +13%（0.052 vs 0.046），属边际改善而非质变。
2. **多重比较警示**：今夜连续测试了约六个条件化方案，单一边际正值落在
   噪声期望内；历史单路径、无样本外验证。
3. 判定：**进观察名单，不立项为部署过滤**。H2 联合检验（读数四）进一步
   否定了独立性——候选的优势集中于去杠杆 regime，独立承接信息的成分存疑。
   后续正确路径是把 absorption 标签接入跟踪器滚动样本（需先解决 CI 运行面
   的 moneyflow 数据可得性），用增量数据自然证实或证伪，而不是继续挖历史。
4. 机制甜点单元格「市场去杠杆 × 无大单派发」（n=161，+230bps）是本轮最
   精细的机制刻画，但两条件交集的历史挖掘多重比较风险更高，仅作机制理解
   记录，不构成规则候选。
