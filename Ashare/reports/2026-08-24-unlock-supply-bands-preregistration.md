# 解禁供给分层带重建：预注册标准（research_only）

- 制定日期：2026-08-24。性质：预注册文档——以下全部定义、边界与判定标准在本
  PR 合入主线时冻结，研究实现 PR 只实现、不改定义；读数在实现落地后一次性产出。
- 动机（#441 HV 段口径发现）：现行 rule 臂回避带（3–5%）建立在公告
  `float_ratio`（解禁股数/总股本，全样本均值≈7.5）之上；daily_basic 的
  流通/总股本（均值≈0.83）是另一个量纲，两者不可互验。经济上更直接的供给
  压力量是「解禁量相对可交易盘的比例」，不是相对总股本的比例——总股本里
  大部分本来就不可交易。

## 预注册定义（冻结）

1. **新变量**：`supply_over_float = float_ratio / (float_share / total_share)`。
   - `float_ratio`：公告值（share_float 面，现行信号字段）。
   - 分母：entry_day 之前最近一个严格早于会话的 daily_basic 行的
     `float_share/total_share`（与换手率/筹码研究同款锚点约定；
     距离纪律沿用 21 自然日陈旧上限，超限拒标）。
2. **固定边界（事前选定，未看任何新变量收益分布）**：
   `< 0.10 → small`；`0.10–0.30 → mid`；`≥ 0.30 → large`
   （解禁占流通盘 10%/30% 两条整数边界；选取依据为市场惯用阈值量级，
   与既有变量分布知识仅限旧 float_ratio 均值≈7.5 × 循环比例≈0.83 的
   尺度推算，未接触新变量与收益的联合分布）。
3. **对照读数（一次性，实现落地后执行）**：
   - R1 分离力对比：同一标注集内，旧 `float_ratio` 三分位 vs 新
     `supply_over_float` 三分位的顶/底组净收益价差与胜率（描述性、
     样本内三分位，只用于口径对比不构成部署证据）。
   - R2 新固定边界交叉表：信号层 small/mid/large + rule 臂叠加
     （纯描述，rule 臂定义不动）。
   - R3 重叠矩阵：旧带（<3 / 3–5 / ≥5）× 新桶计数，量化多少信号跨带移动。
4. **判定标准**：
   - 若 R1 新变量顶/底价差明显大于旧变量且方向单调、且 R3 显示大比例信号
     跨带 ⇒ 立项「规则带替换」独立预注册候选（走自己的预注册+滚动验证，
     **不自动修改 rule 臂**）。
   - 否则 FAIL 记录，现行带保留。两种结果都是合格产出。
5. **HV 数据质量段**：coverage 统计（missing_dailybasic / no_prior /
   stale）；新旧变量应正相关但显著非恒等（相关系数报告，预期 <0.9）。

边界：research_only / not_promotion_evidence；LLM 与本程序无候选、排名、
仓位、风险、订单或账户 authority；本修正不授予任何参数晋升或风险扩张权限。
